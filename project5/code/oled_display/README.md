# 乒乓球 PID 高度悬浮控制系统

> 硬件平台: LCKFB-DKX-STM32F103C8T6 (立创·地阔星)

## 1. 系统概述

在 35cm 透明圆筒中，底部风扇向上吹气，让乒乓球悬浮在指定高度。顶部 HC-SR04 超声波实时测距，STM32 运行 PID 调节风扇转速，形成闭环控制。

```
┌──────────────────────┐  ← 圆筒顶部 (35cm)
│  HC-SR04 超声波       │  传感器朝下, 测量到小球距离 D
│  ═══════════════════ │
│                      │
│      ██ 乒乓球 ██     │  ← 悬浮在气流中
│                      │  小球高度 H = 35 - D (距筒底)
│  ═══════════════════ │
│    ↑↑↑ 风扇 ↑↑↑      │  ← 圆筒底部, 向上吹气
└──────────────────────┘
```

| 参数 | 值 |
|---|---|
| 筒高 | 35 cm |
| 目标高度范围 | 5 ~ 30 cm |
| 超声波盲区 | 2 cm |
| 控制频率 | 50 Hz (每 20ms 一次) |

## 3. MCU 时钟配置

为兼容 **Proteus 仿真** (不模拟外部晶振和 PLL)，系统使用 **HSI 内部 8MHz**:

```
HSI 8MHz → SYSCLK → HCLK(8M) → PCLK1(8M) → TIM2/4
                              → PCLK2(8M) → GPIO
```

`SystemCoreClock = 8000000`，所有定时器预分频**动态计算**:

```c
TIM_Prescaler = (SystemCoreClock / 1000000) - 1;  // 8M → PSC=7 → 1MHz
```

这样换 72MHz 真实硬件时只需恢复 `#define SYSCLK_FREQ_72MHz`，定时器自动适配。

## 4. 超声波测距

### 4.1 原理

```
TRIG: ___/‾‾‾\______________________  10us 触发脉冲
ECHO: ________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\______  脉宽 ∝ 距离

距离(cm) = 脉宽(us) / 58
```

### 4.2 驱动实现

**TIM4 计数器 + GPIO 轮询** (不依赖中断，兼容 Proteus):

1. 发 10us TRIG 脉冲
2. GPIO 轮询等待 ECHO 上升沿 → 读 `TIM4->CNT` 锁存时刻
3. GPIO 轮询等待 ECHO 下降沿 → 读 `TIM4->CNT` 锁存时刻
4. 脉宽 = 两时刻之差 (1us 精度，处理 16 位溢出)
5. 超时也用 TIM4 真实时间 (不用循环计数)
6. 距离 = 脉宽(us) / 58.0

### 4.3 高度换算

```c
if (超声距离 <= 2cm 或 > 40cm) → 无效, 保持上次高度
height = 35.0 - 超声距离        // 有效范围: -5 ~ 33cm (仅 5~30 允许设目标)
```

## 5. 风扇 PWM (L298N)

| IN1 | IN2 | ENA (PWM) | 结果 |
|---|---|---|---|
| H | L | 0~100% | 正转调速 |
| L | L | — | 停止 |

- PWM 频率: **1kHz** (ARR=999)
- 占空比: CCR 0~1000 → 0%~100%
- 速度映射: `s8 speed(-100~100) × 10 = CCR`

## 6. PID 控制器

### 6.1 算法

**位置式 PID + 变速积分 + 输出限幅**

```
u(t) = Kp·e(t) + Ki·∫e(t)dt + Kd·de/dt
```

| 特性 | 说明 |
|---|---|
| 变速积分 | \|e\| > 20cm 时冻结积分，防大误差饱和 |
| 积分限幅 | ±30，防 windup |
| 微分 | 测量值微分 (避免设定值突变冲击) |
| 输出限幅 | 0 ~ 100 (%) |

### 6.2 参数

| 参数 | 值 | 含义 |
|---|---|---|
| Kp | 3.0 | 1cm 误差 → 3% PWM |
| Ki | 0.05 | 稳态误差消除速度 |
| Kd | 1.5 | 振荡抑制 |
| 积分限幅 | 30 | 积分项最大贡献 ±30% |

### 6.3 关键函数

```c
PID_Init()      // 清零所有状态
PID_Setpoint()  // 更新目标值 + 清零积分/微分
PID_Compute()   // 每 20ms 调用, 返回 0~100
```

## 7. 运行逻辑

### 7.1 主循环 (10ms 节拍)

```
while (1):
    ┌─ 按键扫描 (每次循环)
    ├─ 超声波测距 + 控制 (每 20ms)
    ├─ OLED 刷新        (每 250ms)
    └─ delay_ms(10)
```

### 7.2 按键 → 目标高度

| 按键 | 目标 |
|---|---|
| `0`~`9` | 10, 15, 16, 17, 18, 19, 20, 21, 22, 23 cm |
| `A`~`D` | 25, 28, 30, 12 cm |
| `*` | 停止风扇 (目标保持, 可恢复) |
| `#` | **急停** (风扇关, PID 复位, 全部清零) |

### 7.3 状态机

```
                 按键设目标
  ┌──────┐       ┌──────────┐        ┌──────────┐
  │ 空闲  │ ───→ │ 起飞助推  │ ───→  │ PID 稳悬  │
  │风扇关 │       │ 风扇 100% │        │ 50Hz 调节 │
  └──────┘       └──────────┘        └────┬─────┘
      ↑              │                    │
      │    */#       │   #急停            │ */#
      └──────────────┴────────────────────┘
```

### 7.4 起飞助推 (关键设计)

球在筒底时重力 > 初始气流升力，PID 从 0% 慢慢爬升永远吹不起来。因此加入助推:

```
助推触发: 每次 set_target() 时自动开启

助推期间:
  • fan = 100% (满功率)
  • 不运行 PID (避免误差累积导致积分饱和)

退出条件 (全部满足):
  ① 高度 ≥ 目标 - 3cm    (球已接近目标)
  ② 高度 ≥ 0.5cm         (球确实离开筒底, 防噪声误判)

退出动作:
  • 重置 PID (积分清零)
  • 以当前高度为起点切 PID 稳悬

无时间限制: 球没到位就一直满功率吹
```

### 7.5 高度测量与滤波

```
HC_SR04 读距 → sonic_to_height() 换算高度
                  │
                  ├─ 无效? → 丢弃, 保持上次值
                  │
                  └─ 有效? → 一阶低通滤波 (α=0.3)
                              g_height = 0.3×新值 + 0.7×旧值
```

超声波超时 (sonic=0) 时保持上次高度，避免传感器丢包导致控制跳变。

### 7.6 PID 稳悬 (每 20ms)

```
1. error = target - height
2. P = Kp × error
3. I = Ki × ∫error·dt  (|error| < 20cm 才累加)
4. D = Kd × d(height)/dt  (测量值微分)
5. output = clamp(P+I+D, 0, 100)
6. fan = round(output)
7. L298N_Motor_Set(fan)
```

### 7.7 急停

`#` 键: 风扇关 + PID 复位 + 目标清零 + 助推标志清零 + 超声状态清零

`*` 键: 风扇关 + g_running=0 (目标保持不变，可重新按键恢复)

## 8. OLED 显示

```
┌────────────────────┐  行0: 标题 "Levitation Ctrl"
│ Levitation Ctrl    │
│ H: 15.0cm          │  行2: 当前高度 (滤波后)
│ T: 15.0 F: 45%     │  行4: 目标高度 + 风扇转速

└────────────────────┘
```

特殊显示:
- `H: ---.-cm` — 超声波尚无有效读数
- `S: xx.xcm OOR` — 超声原始距离超出筒范围 (调试用, OOR = Out Of Range)
- `T: --.- STOPPED` — 风扇已停止
- `F:100%` — 助推阶段满功率

## 9. 调参指南

### PID 整定顺序

1. **先 P**: Ki=0, Kd=0。从 2.0 开始增到球能悬但振荡，然后 ×0.6
2. **再加 D**: 从 0.5 增到振荡消失
3. **最后 I**: 从 0.01 增到稳态误差 < 0.5cm

### 常见问题

| 现象 | 原因 | 调整 |
|---|---|---|
| 球吹不起来 | 风扇不够力 / L298N 压降 | 提高电源电压, 或换 MOSFET 驱动 |
| 助推不退出 | 球达不到目标高度 | 检查风扇功率, 降低目标试试 |
| 球振荡大 | Kp 太大 或 Kd 太小 | ↓Kp 或 ↑Kd |
| 球稳在错误高度 | Ki 太小 | ↑Ki |
| 响应太慢 | Kp 太小 | ↑Kp |
| 显示 OOR | 超声距离 > 40cm | Proteus 超声距离设为 2~40cm 内 |

## 10. 开发备忘
