  压力注射装置 - 系统工作原理详解
================================================================================

================================================================================
一、系统启动流程
================================================================================

上电 → main() 按以下顺序执行:

  Step 1: delay_init()
          └─ 配置 SysTick = HCLK/8 = 9MHz (72MHz/8)
          └─ 提供 delay_us() 和 delay_ms() 精确延时
          └─ 此时系统时钟 = 72MHz (HSE 8MHz × PLL9)

  Step 2: OLED_Init()
          └─ 使能 GPIOB 时钟
          └─ 配置 PB12(SCL) PB13(SDA) 为推挽输出
          └─ 通过软件I2C发送SSD1306初始化命令序列
          └─ 清屏, 显示 "Injector Sys" / "Init..."
          └─ 此时OLED开始工作

  Step 3: GPIO_Motor_Init()
          └─ 配置 PA10/PA11/PA12/PA13 为推挽输出
          └─ 全部拉低, 电机各相断电

  Step 4: ADC_Poll_Init()
          └─ 使能 GPIOA + ADC1 时钟
          └─ ADC时钟 = 72MHz/6 = 12MHz
          └─ 配置 PA0(压力) PA1(电池) 为模拟输入
          └─ ADC1: 独立模式, 单通道, 软件触发
          └─ ADC校准(硬件自动校准)

  Step 5: Key_Init()
          └─ 使能 GPIOB + GPIOA + AFIO 时钟
          └─ 禁止JTAG(PB3/PB4/PA15释放为GPIO)
          └─ 配置 PB0=下拉输入(KEY1)
          └─ 配置 PA5/PA6=下拉输入(KEY2/KEY3)
          └─ 配置 PA15=推挽输出(按键反馈LED)

  Step 6: Alarm_Init()
          └─ 使能 GPIOB 时钟
          └─ 配置 PB3=推挽输出(蜂鸣器)
          └─ 配置 PB4=推挽输出(报警LED)
          └─ 初始状态: 全部关闭

  Step 7: EEPROM_Init()
          └─ 使能 GPIOA 时钟
          └─ 配置 PA8(SCL) PA9(SDA) 为开漏输出
          └─ 释放I2C总线(拉高), 等待10ms稳定

  Step 8: TIM2_Motor_Init()
          └─ 使能 TIM2 时钟(APB1)
          └─ 预分频 72-1 → 72MHz/72 = 1MHz (1us计数)
          └─ 自动重载 1000-1 → 1ms周期(占位值)
          └─ TIM2初始状态: 关闭 (电机未转时不耗CPU)
          └─ 配置NVIC: 抢占优先级0(最高), 响应优先级0

  Step 9: TIM3_KeyScan_Init()
          └─ 使能 TIM3 时钟(APB1)
          └─ 预分频 72-1 → 1MHz
          └─ 自动重载 16000-1 → 16ms周期
          └─ TIM3立即启动
          └─ 配置NVIC: 抢占优先级2, 响应优先级0

  Step 10: EEPROM_LoadConfig()
           └─ 读EEPROM地址0x00(语言标志)
           └─ 如果是0xFF(新片)或无效值 → 写入默认值
           └─ 读取 p_set, 版本号, 最大容积, 压迫时间
           └─ 填入全局变量 g_ee_xxx

  Step 11: memset(&g_rt, 0, sizeof(g_rt))
           └─ 清零所有运行时数据

  Step 12: 显示 "System Ready" 500ms → 进入 IDLE 待机


================================================================================
二、主循环工作原理 (while(1) 中的执行流)
================================================================================

主循环每次迭代执行3件事，无阻塞:

  ┌──────────────────────────────────────────────────┐
  │  while (1) {                                    │
  │                                                 │
  │    //=== 第1部分: 定时任务 (100ms周期) ======== │
  │    if (g_sys_tick - last >= 100) {  ──────────┐ │
  │      Sensor_Read();          读传感器(16次ADC) │ │
  │      Alarm_Check();          安全检查          │ │
  │      OLED_Update();          刷新显示          │ │
  │      blink更新;              闪烁计数器        │ │
  │    } ─────────────────────────────────────────┘ │
  │                                                 │
  │    //=== 第2部分: 按键处理 (每次循环都执行) === │
  │    Key_Process();                               │
  │                                                 │
  │    //=== 第3部分: 状态机 (每次循环都执行) ====  │
  │    switch(g_state) {                            │
  │      case STATE_IDLE:     State_Idle();         │
  │      case STATE_SETUP:    State_Setup();        │
  │      case STATE_PURGE:    State_Purge();        │
  │      case STATE_INJECT:   State_Inject();       │
  │      case STATE_COMPRESS: State_Compress();     │
  │      case STATE_RETRACT:  State_Retract();      │
  │      case STATE_ERROR:    State_Error();        │
  │    }                                            │
  │  }                                              │
  └──────────────────────────────────────────────────┘

关键设计:
  - 传感器采样/显示刷新 = 固定100ms周期(10Hz)
  - 按键扫描 = 每次循环都检查(响应快,但内部有消抖保护)
  - 状态机 = 每次循环都执行(状态转移无延迟)
  - 所有函数都是非阻塞的, 循环不会卡死


================================================================================
三、中断系统工作
================================================================================

系统有3个中断源在后台并行工作:

┌─────────────────────────────────────────────────────────────────┐
│  中断1: SysTick (系统滴答)                                      │
│  ─────────────────────────────────────────────────────────────  │
│  频率: 每1ms触发一次 (由delay_init配置)                        │
│  用途: delay_us() / delay_ms() 的时基                          │
│  实现: 硬件SysTick计数器, 在delay.c中                          │
│  注:   不产生用户可见的中断服务, 仅用于延时循环中的轮询         │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  中断2: TIM2 (电机步进控制) — 最高优先级                        │
│  ─────────────────────────────────────────────────────────────  │
│  触发: 每次TIM2计数溢出(周期由电机速度决定)                     │
│  优先级: 抢占0 (最高, 不会被其他中断打断)                      │
│  功能:                                                          │
│    TIM2_IRQHandler() {                                          │
│      1. 清除中断标志                                            │
│      2. 如果电机未运行 → 直接返回                               │
│      3. g_motor_step_cnt++  (步数计数+1)                        │
│      4. 如果达到目标步数:                                       │
│           → g_motor_running = 0                                 │
│           → 关闭TIM2                                             │
│           → 所有电机相断电                                       │
│           → 返回                                                 │
│      5. g_motor_step_idx++  (相位指针+1, 0~7循环)               │
│      6. 根据方向查表, 输出对应相到 PA10~PA13                    │
│    }                                                             │
│                                                                  │
│  时序示例 (速度=1000Hz, 即周期=1000us):                          │
│    t=0us:    中断→输出相0(AB)                                    │
│    t=1000us: 中断→输出相1(B)                                     │
│    t=2000us: 中断→输出相2(BC)                                    │
│    t=3000us: 中断→输出相3(C)                                     │
│    ...以此类推, 形成连续旋转磁场, 驱动步进电机转动               │
│                                                                  │
│  软启动实现:                                                     │
│    - 在State_Inject()中, 前100步内逐次调用Motor_SetSpeed()       │
│    - 每次更新TIM2的自动重载寄存器, 改变中断频率                   │
│    - 速度从300Hz线性上升到1200Hz, 实现平滑加速                   │
│    - 重载寄存器的修改在下一次溢出时生效(硬件同步)                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  中断3: TIM3 (系统时基)                                         │
│  ─────────────────────────────────────────────────────────────  │
│  触发: 每16ms一次 (固定)                                        │
│  优先级: 抢占2 (可被TIM2打断)                                   │
│  功能:                                                          │
│    TIM3_IRQHandler() {                                          │
│      g_sys_tick += 16;  // 累加系统时间(ms)                     │
│    }                                                             │
│                                                                  │
│  注意: g_sys_tick 是 volatile 变量, 主循环读取, 中断写入         │
│  每16ms加16, 即每ms等效增加1 → g_sys_tick 的单位是ms            │
│                                                                  │
│  主循环用它做定时判断:                                           │
│    if (g_sys_tick - last >= 100) → 100ms到了, 刷新显示          │
│    now_sec = g_sys_tick / 1000   → 换算为秒                     │
└─────────────────────────────────────────────────────────────────┘


================================================================================
四、具体工作场景示例
================================================================================

场景: 上电 → 设置参数 → 注射 → 压迫 → 回抽 → 查看结果

【阶段1: 待机 IDLE】
────────────────────────────────────────
  循环快速迭代(每圈约几十微秒)

  迭代1:
    ├─ 系统滴答检查: tick不够100 → 跳过显示更新
    ├─ Key_Process(): Key_Scan()返回0 → 跳过
    └─ State_Idle(): g_page = PAGE_STANDBY

  迭代2~N: 同上(空转等待)

  迭代(100ms时):
    ├─ tick够了 → Sensor_Read()
    │   ├─ ADC_ReadAvg(PA0压力, 8次) → 16次ADC转换
    │   │   每次: 配置通道→启动→等EOC→读数 (约20us×16=320us)
    │   ├─ ADC_ReadAvg(PA1电池, 8次)
    │   ├─ 计算: pressure = 电压/3.3*500.0 → kPa
    │   ├─ 计算: battery  = 电压/3.3*100.0 → %
    │   └─ 更新 max_pressure / pressure_sum / pressure_count
    │
    │   假设读到: pressure=0kPa, battery=85%
    │
    ├─ Alarm_Check():
    │   pressure=0 < 450 → 不过压
    │   battery=85 > 10 → 不低电量
    │   → 无报警
    │
    └─ OLED_Update():
        OLED_ShowStandby() 输出:
        ┌──────────────────┐
        │ BAT: 85%    IDLE │
        │ v1.0 EN          │
        │ Pset: 30.0 kPa   │
        │ KEY1:Start       │
        └──────────────────┘

【阶段2: 用户按下KEY1 → 进入SETUP】
────────────────────────────────────────
  Key_Process():
    KEY_Scan(0) 检测到 PB0=1 (按键按下)
    → 延时10ms消抖
    → 再次确认 PB0=1
    → 返回 KEY1_PRES

  switch(g_state) case STATE_IDLE:
    KEY1_PRES → g_state = STATE_SETUP
    OLED_Update() 立即刷新显示

  现在显示变为(参数可调):
        ┌──────────────────┐
        │ BAT: 85%    IDLE │  ← SETUP也用待机页面
        │ v1.0 EN          │
        │ Pset: 30.0 kPa   │  ← 可调整的参数
        │ KEY1:Start       │
        └──────────────────┘

  用户按KEY2: g_ee_p_set += 5 → 30.5 kPa → EEPROM保存 → 刷新
  用户按KEY2: g_ee_p_set += 5 → 31.0 kPa → EEPROM保存 → 刷新
  用户按KEY3: g_ee_p_set -= 5 → 30.5 kPa → EEPROM保存 → 刷新

【阶段3: 用户按下KEY1确认 → 进入PURGE】
────────────────────────────────────────
  Key_Process() case STATE_SETUP:
    KEY1_PRES →
    ├─ Buzzer_Beep(1, 50ms)        → PB3输出50ms高电平
    ├─ g_state = STATE_PURGE
    ├─ g_page = PAGE_MONITOR
    └─ Motor_Start(正向, 50步, 300Hz)
         ├─ 计算: period = 1000000/300 = 3333us
         ├─ g_motor_running = 1
         ├─ g_motor_ramping = 1
         ├─ 输出初始相: PA10/PA11 = 高
         └─ TIM2 ARR = 3333-1, 启动TIM2

  → TIM2开始每3.3ms触发一次中断
    每次中断电机转1步(1/8相)
    50步后: g_motor_running=0, TIM2关闭

  State_Purge():
    检测到 !g_motor_running →
    ├─ g_state = STATE_INJECT
    ├─ 重置 max_pressure=0, pressure_sum=0, pressure_count=0
    └─ Motor_Start(正向, 350步, 300Hz)  ← 开始正式推注!

【阶段4: 推注 INJECT + 软启动】
────────────────────────────────────────
  Motor_Start 启动后, 每100ms:
    ├─ Sensor_Read() → 实时压力不断更新
    ├─ State_Inject():
    │
    │  // 更新推注量
    │  g_rt.volume = g_motor_step_cnt / 500  (步数→mL)
    │
    │  // 软启动: 前100步内逐步加速
    │  if (g_motor_ramping && step_cnt < 100)
    │     speed = 300 + (1200-300)*step_cnt/100
    │     例: step=0  → speed=300Hz
    │         step=25 → speed=525Hz
    │         step=50 → speed=750Hz
    │         step=75 → speed=975Hz
    │         step=99 → speed=1191Hz
    │     Motor_SetSpeed(speed) → 更新TIM2周期
    │
    │  // 停止条件检查 (每次循环都判断)
    │  if (pressure >= p_set)  → 压力达标, 停止
    │  if (volume >= 0.7mL)    → 容积达标, 停止
    │  if (g_stop_flag)        → 手动/紧急停止
    │
    └─ OLED显示:
        ┌──────────────────┐
        │ P:  125.3 kPa    │
        │ Vol: 0.35 mL     │
        │ T:  --:-- INJECT │
        │ RUN              │
        └──────────────────┘

  假设压力先达到30.0kPa:
    停止条件触发 →
    ├─ g_stop_flag = 1
    ├─ Motor_Stop() → 关TIM2, 电机相断电
    ├─ g_state = STATE_COMPRESS
    ├─ compress_start = 当前系统秒数
    ├─ compress_remain = 600 (10分钟)
    ├─ history_idx = 0
    ├─ Buzzer_Beep(2, 100ms) → PB3响2声

【阶段5: 压迫计时 COMPRESS】
────────────────────────────────────────
  每100ms:
    ├─ Sensor_Read() → 持续监控压力(但电机已停)
    │   压力逐渐回落...
    │
    ├─ State_Compress():
    │
    │  // 计算剩余时间
    │  now_sec = g_sys_tick / 1000
    │  elapsed = now_sec - compress_start
    │  remain = 600 - elapsed
    │
    │  // 每5秒存一次压力点到EEPROM
    │  if (now_sec - last_history_tick >= 5) {
    │    last_history_tick = now_sec
    │    p_x10 = (uint16_t)(pressure * 10)  // 例: 125.3kPa → 1253
    │    pressure_history[history_idx] = p_x10  // RAM中
    │    EEPROM_SavePressurePoint(idx, p_x10)   // EEPROM中(掉电不丢)
    │    history_idx++
    │  }
    │
    │  // 压迫时间到?
    │  if (remain == 0) {
    │    g_state = STATE_RETRACT
    │    Motor_Start(反向, 350步, 1200Hz)
    │    Buzzer_Beep(3, 200ms)
    │  }
    │
    └─ OLED显示:
        ┌──────────────────┐
        │ P:  28.5 kPa     │  ← 压力已回落
        │ Vol: 0.35 mL     │  ← 推注量不变
        │ T:  08:42  HOLD  │  ← 倒计时
        │ RUN              │
        └──────────────────┘

  10分钟倒计时归零时, EEPROM中已保存120个压力点
  (600秒/5秒=120点, 每个uint16, 共240字节)

【阶段6: 回抽 RETRACT】
────────────────────────────────────────
  Motor_Start(反向):
    → 电机反转, 按反向步进序列表驱动
    → 350步(对应0.7mL)全速(1200Hz)回抽

  每100ms刷新显示:
    电机运行中 → PAGE_MONITOR
        ┌──────────────────┐
        │ P:  0.5 kPa      │
        │ Vol: 0.00 mL     │
        │ T:  --:-- RETRACT│
        │ RUN              │
        └──────────────────┘

  电机停止后:
    State_Retract():
    ├─ g_page = PAGE_RESULT
    ├─ Buzzer_Beep(1, 500ms) → 长鸣一声提示
    └─ 显示结果:
        ┌──────────────────┐
        │ -- Results --    │
        │ Pmax:  156.2 kPa │
        │ Pavg:  142.8 kPa │
        │ Vol:    0.68 mL  │
        └──────────────────┘

  Key_Process() case STATE_RETRACT:
    电机已停 + KEY1:
    ├─ g_state = STATE_IDLE
    ├─ g_page  = PAGE_STANDBY
    └─ 回到待机, 可开始下一次注射


================================================================================
五、安全机制工作方式
================================================================================

【过压保护】
  Alarm_Check() 每100ms检查:
  if (pressure > 450.0 kPa) {
    EnterError(1) →
    ├─ g_error_code = 1
    ├─ g_state = STATE_ERROR   ← 状态立即切换
    ├─ Motor_EmergencyStop()   ← 关TIM2+电机断电+置STOP标志
    ├─ Alarm_On()              ← PB3=1(蜂鸣), PB4=1(LED)
    └─ EEPROM_WriteByte(0xF0, 1) ← 记录错误码
  }

  State_Error():
    → 显示错误页面 (不依赖g_page, 直接写OLED)
    → 电机保持锁定状态
    → 报警持续

  用户按KEY1:
    Key_Process() case STATE_ERROR:
    ├─ Alarm_Off()         ← 关闭蜂鸣和LED
    ├─ g_error_code = 0
    ├─ g_state = STATE_IDLE
    └─ 返回待机

【低电量保护】
  同上流程, 错误码=2


================================================================================
六、定时关系总结
================================================================================

  时间轴示意图 (以一次完整注射为例):

  t=0s     上电初始化 (~1.5s)
  t=1.5s   进入IDLE, 屏幕开始刷新
  t=3s     用户按KEY1 → SETUP
  t=5s     用户调参数(KEY2×3, KEY3×1) → p_set=35.0kPa
  t=6s     用户按KEY1确认 → PURGE排气
  t=6.2s   排气完成(50步/300Hz≈0.17s) → 自动进入INJECT
  t=6.2s   推注开始, 软启动加速
  t=6.4s   软启动完成(100步, 从300Hz加速到1200Hz)
  t=6.6s   推注约0.4mL, 压力上升到目标值
  t=6.6s   达到p_set → 停止, 进入COMPRESS
  t=6.6s   压迫计时开始(10min=600s)
  t=11.6s  第1个压力采样点(5s) → EEPROM
  t=16.6s  第2个压力采样点(10s) → EEPROM
  ...每5s一个采样点...
  t=606.6s 第120个采样点(600s) → EEPROM, 压迫时间到
  t=606.6s 进入RETRACT, 电机反转
  t=606.9s 回抽完成(350步/1200Hz≈0.3s)
  t=606.9s 显示结果摘要, 蜂鸣长响
  t=608s   用户按KEY1 → 返回IDLE

  总耗时约10分钟(主要是压迫计时的10分钟)

  系统Tick分辨率:    16ms (TIM3中断周期)
  显示刷新周期:      100ms (10Hz)
  ADC采样耗时:       ~640us (16次ADC转换×40us)
  TIM2中断最高频率:  1200Hz (最快步进速度时)
  TIM2中断最短间隔:  ~833us (1200Hz时)
  按键消抖延时:      10ms
  EEPROM写入延时:    10ms/字节 (写入周期等待)
