================================================================================
  压力注射装置 - 显示功能与按键功能详细说明
  Pressure Injection System - Display & Key Function Reference
================================================================================

版本: v1.0
硬件: STM32F103C8 + OLED 128x64 (SSD1306 I2C)

================================================================================
一、OLED 显示界面 (三级菜单结构)
================================================================================

┌─────────────────────────────────────────────────────────────┐
│  第一级: 待机主界面 (PAGE_STANDBY)                            │
│  显示条件: g_state == STATE_IDLE 或 STATE_SETUP               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  BAT: 85%            IDLE                                    │
│                                                             │
│  v1.0 EN                                                    │
│                                                             │
│  Pset: 30.0 kPa                                             │
│                                                             │
│  KEY1:Start                                                 │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  行0: 电池电量(%)  +  当前工作模式(IDLE)                       │
│  行2: 版本号  +  语言(EN=英文 / CN=中文)                       │
│  行4: 目标压力设定值(kPa)                                     │
│  行6: 操作提示 "KEY1:Start"                                   │
│                                                             │
│  刷新率: 10Hz (每100ms更新一次)                                │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  第二级: 实时监测界面 (PAGE_MONITOR)                           │
│  显示条件: STATE_PURGE / STATE_INJECT / STATE_COMPRESS /      │
│           STATE_RETRACT (电机运行时)                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  P:  125.3 kPa                                              │
│                                                             │
│  Vol:  0.35 mL                                              │
│                                                             │
│  T:  08:42         INJECT                                   │
│                                                             │
│  RUN                                                        │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  行0: 实时压力值(kPa), 较大字号显示                            │
│  行2: 已推注量(mL)                                            │
│  行4: 剩余压迫时间(mm:ss) + 当前状态(PURGE/INJECT/HOLD/RETRACT) │
│  行6: 运行状态 RUN(运行中) / STOP(闪烁,已停止)                  │
│                                                             │
│  刷新率: 10Hz                                                 │
│  注意: 仅COMPRESS状态显示剩余时间, 其他状态显示 "--:--"          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  第三级: 结果摘要界面 (PAGE_RESULT)                            │
│  显示条件: STATE_RETRACT (电机停止后, 回抽完成)                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  -- Results --                                              │
│                                                             │

│                                                             │

│                                                             │

│                                                             │

│  行0: 标题 "-- Results --"                                    │
│  行2: 最大压力(kPa)                                           │
│  行4: 平均压力(kPa)                                           │
│  行6: 总推注量(mL)                                            │
│                                                             │
│  操作: 按KEY1返回待机界面                                      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  特殊界面: 错误界面 (ERROR状态)                                │
│  显示条件: g_state == STATE_ERROR                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  !! ERROR !!                                                │
│                                                             │
│  Code: 1                                                    │
│                                                             │
│  Motor Locked                                               │
│                                                             │
│  KEY1:Reset                                                 │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  行0: 错误标题 "!! ERROR !!"                                   │

================================================================================
二、按键功能 (Key Functions)
================================================================================

┌──────────────────────────────────────────────────────────────┐
│  硬件连接:                                                     │
│  ┌────────┬──────────┬─────────────────────────────────────┐ │
│  │  按键  │  引脚    │  功能描述                            │ │
│  ├────────┼──────────┼─────────────────────────────────────┤ │
│  │  KEY1  │  PB0     │  确认 / 启动 / 停止 / 复位           │ │
│  │  KEY2  │  PA5     │  参数增大 / 下一个                    │ │
│  │  KEY3  │  PA6     │  参数减小 / 返回                      │ │
│  └────────┴──────────┴─────────────────────────────────────┘ │
│                                                              │
│  按键特性:                                                    │
│  - 软件消抖: 10ms延时确认                                     │
│  - 防连击: 按下后必须释放才能再次触发                           │
│  - 按下时PA15(KEY_LED)亮起作为按键反馈                         │
│  - 按键扫描由主循环轮询, 无独立中断                             │
└──────────────────────────────────────────────────────────────┘

========== 各状态下的按键行为 ==========

状态: STATE_IDLE (待机)
┌────────┬────────────────────────────────────────────┐
│  KEY1  │ 进入 SETUP 状态, 可设置注射参数              │
│  KEY2  │ 无操作                                      │
│  KEY3  │ 无操作                                      │
└────────┴────────────────────────────────────────────┘

状态: STATE_SETUP (参数设置)
┌────────┬────────────────────────────────────────────┐
│  KEY1  │ 确认参数, 蜂鸣1声(50ms),                    │
│        │ 保存配置到EEPROM, 进入PURGE状态并启动电机     │
│  KEY2  │ 增大目标压力 g_ee_p_set (+0.5 kPa)          │
│        │ 上限: 500.0 kPa, 调整后自动保存到EEPROM       │
│  KEY3  │ 减小目标压力 g_ee_p_set (-0.5 kPa)          │
│        │ 下限: 1.0 kPa, 调整后自动保存到EEPROM         │
└────────┴────────────────────────────────────────────┘

状态: STATE_PURGE (排气)
┌────────┬────────────────────────────────────────────┐
│  KEY1  │ 无操作 (自动过渡到INJECT)                    │
│  KEY2  │ 无操作                                      │
│  KEY3  │ 无操作                                      │
│  说明  │ 电机前进小段距离排气后自动进入INJECT          │
└────────┴────────────────────────────────────────────┘

状态: STATE_INJECT (推注)
┌────────┬────────────────────────────────────────────┐
│  KEY1  │ 紧急停止! 设置STOP标志, 停止电机,            │
│        │ 立即进入COMPRESS压迫计时                     │
│  KEY2  │ 无操作                                      │
│  KEY3  │ 无操作                                      │
│  自动  │ 达到目标压力OR推注量≥0.7mL → 自动停止并进入   │
│  停止  │ COMPRESS状态, 蜂鸣2声(各100ms)               │
└────────┴────────────────────────────────────────────┘

状态: STATE_COMPRESS (压迫计时)
┌────────┬────────────────────────────────────────────┐
│  KEY1  │ 手动提前结束压迫, 进入RETRACT回抽             │
│  KEY2  │ 无操作                                      │
│  KEY3  │ 无操作                                      │
│  自动  │ 10分钟倒计时归零 → 自动进入RETRACT,           │
│        │ 蜂鸣3声(各200ms)提示压迫完成                  │
│  后台  │ 每5秒自动采样压力并保存到EEPROM(共120点)      │
└────────┴────────────────────────────────────────────┘

状态: STATE_RETRACT (回抽)
┌────────┬────────────────────────────────────────────┐
│  电机  │ KEY1 紧急停止电机                            │
│  运行  │                                              │
│  时    │                                              │
├────────┼────────────────────────────────────────────┤
│  电机  │ KEY1 返回待机IDLE状态                        │
│  停止  │ (回抽完成后自动显示结果摘要, 蜂鸣1声500ms)    │
│  后    │                                              │
└────────┴────────────────────────────────────────────┘

状态: STATE_ERROR (错误)
┌────────┬────────────────────────────────────────────┐
│  KEY1  │ 清除错误, 关闭报警, 返回IDLE待机              │
│  KEY2  │ 无操作 (电机已锁定)                          │
│  KEY3  │ 无操作 (电机已锁定)                          │
└────────┴────────────────────────────────────────────┘


================================================================================
三、状态机完整流程
================================================================================

                    ┌──────────┐
                    │  上电     │
                    └────┬─────┘
                         │ 初始化外设, 加载EEPROM配置
                         ▼
               ┌─────────────────┐
               │     IDLE        │  显示: 待机界面
               │    (待机)       │  KEY1 → SETUP
               └────────┬────────┘
                        │ KEY1
                        ▼
               ┌─────────────────┐
               │    SETUP        │  显示: 待机界面(可调参数)
               │   (参数设置)     │  KEY2/KEY3 → 调整p_set
               └────────┬────────┘  KEY1 → PURGE
                        │ KEY1 (确认)
                        ▼
               ┌─────────────────┐
               │    PURGE        │  显示: 监测界面
               │    (排气)       │  电机前进一小段 → 自动
               └────────┬────────┘
                        │ 电机停止 (自动)
                        ▼
               ┌─────────────────┐
               │    INJECT       │  显示: 监测界面
               │    (推注)       │  电机前进, 软启动斜坡加速
               └────────┬────────┘  KEY1 → 紧急停止
                        │ 压力达标 OR 容积达标 OR KEY1停止
                        ▼
               ┌─────────────────┐
               │   COMPRESS      │  显示: 监测界面(倒计时)
               │   (压迫计时)     │  10分钟, 每5s存压力点到EEPROM
               └────────┬────────┘  KEY1 → 提前结束
                        │ 10分钟到 (自动)
                        ▼
               ┌─────────────────┐
               │   RETRACT       │  显示: 监测界面→结果界面
               │    (回抽)       │  电机反转, 抽回活塞
               └────────┬────────┘  KEY1(完成后) → IDLE
                        │ 电机停止 (自动)
                        ▼
               ┌─────────────────┐
               │  显示结果摘要     │  显示: 结果界面
               │  (Pmax/Pavg/Vol) │  KEY1 → IDLE
               └────────┬────────┘
                        │ KEY1
                        ▼
               ┌─────────────────┐
               │     IDLE        │  (循环)
               └─────────────────┘

   ╔══════════════════════════════════════════════════╗
   ║  任何状态 ──(过压/低电量)──►  ERROR (错误锁定)  ║
   ║  KEY1清除错误 → IDLE                             ║
   ╚══════════════════════════════════════════════════╝

四、错误代码说明
================================================================================

┌────────┬──────────┬──────────────────────────────────┐
│  代码  │  触发条件 │  处理动作                         │
├────────┼──────────┼──────────────────────────────────┤
│   1    │  过压     │  压力 > 450.0 kPa                │
│        │          │  电机紧急停止, 蜂鸣+LED报警        │
│        │          │  错误码存入EEPROM 0xF0             │
├────────┼──────────┼──────────────────────────────────┤
│   2    │  低电量   │  电池 < 10% (且 > 0%)             │
│        │          │  电机紧急停止, 蜂鸣+LED报警        │
│        │          │  错误码存入EEPROM 0xF0             │
└────────┴──────────┴──────────────────────────────────┘


================================================================================
五、EEPROM存储布局
================================================================================

┌──────────┬──────┬────────────────────────────────────┐
│  地址    │ 字节 │  内容                               │
├──────────┼──────┼────────────────────────────────────┤
│  0x00    │  1   │  语言设置 (0=中文, 1=英文)           │
│  0x01-02 │  2   │  目标压力 p_set (uint16, 单位0.1kPa) │
│  0x03    │  1   │  主版本号                           │
│  0x04    │  1   │  次版本号                           │
│  0x05    │  1   │  最大推注量 (单位0.1mL)              │
│  0x06    │  1   │  压迫时间 (分钟)                     │
│  0x07-0F │  9   │  保留                               │
│  0x10-0xFF│ 240 │  压力曲线120点 (每点2字节, 5s采样)    │
│  0xF0    │  1   │  最近错误代码 (LOG)                  │
└──────────┴──────┴────────────────────────────────────┘
