功能需求
OLED显示界面采用三级菜单结构:顶层为待机主界面,显示电池电量、当前工作模式和版本号;进入工作状态后切换到实时监测界面,用较大字号显示压力(kPa)、已推注量(mL)和剩余压迫时间;压迫结束后显示结果摘要界面,包括最大压力、平均压力、总推注量等。界面刷新率10Hz,保证数据实时更新的同时不过度占用MCU资源。所有界面的中英文切换通过EEPROM设置位实现,方便国际化扩展。
软件系统基于STM32CubeHAL库开发,采用模块化设计思路,分为启动引导、初始化、主循环、中断服务四个层次。主程序流程如图4.6所示:系统上电后完成各外设初始化和传感器零位补偿;进入待机态等待用户按键;检测到启动键后读取参数、打开电机驱动,TIM2产生PWM脉冲驱动电机前进,ADCDMA连续采集压力;若达到p_set或推注满0.7mL或任一安全条件触发,立刻置位STOP标志,关闭TIM2,进入压迫计时;计时满10min后电机反转抽回活塞、提示拔管。全过程压力曲线保存至片内2KBEEPROM,共可存储120个压力采样点每次(分辨率5s/点)。
软件系统核心模块共分为七个部分:系统初始化模块、按键扫描模块、OLED显示模块、电机控制模块、压力采集模块、状态机模块和数据存储模块。系统初始化模块在上电后按顺序完成时钟树配置、GPIO初始化、ADC标定、定时器初始化、I2C总线扫描和EEPROM读取;按键扫描模块采用16ms周期定时器中断,具备消抖、防连击和长按识别功能;OLED显示模块基于SSD1306命令集,采用半屏刷新策略以降低I2C总线占用率;电机控制模块通过TIM2硬件输出PWM脉冲,支持软启动软停止,避免失步;压力采集模块采用DMA循环采集8点取平均,有效抑制随机噪声。
状态机是软件的核心,整个装置被抽象为7个状态:待机(IDLE)、参数设置(SETUP)、排气(PURGE)、推注(INJECT)、压迫计时(COMPRESS)、抽回(RETRACT)、错误(ERROR)。状态转移由按键事件、定时器事件和传感器事件触发,保证程序逻辑清晰、可测试、可维护。特别地,ERROR状态作为"安全兜底",在检测到任何异常(过压、电机失步、电池过低等)时立即进入,锁定电机、发出声光报警、保存异常日志,防止因程序故障造成医疗事故。
