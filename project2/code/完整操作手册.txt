六、EEPROM 存储布局
================================================================================

  ┌───────────┬───────┬───────────────────────────────┐
  │  地址     │  字节 │  内容                          │
  ├───────────┼───────┼───────────────────────────────┤
  │  0x00     │   1   │  语言: 0=中文, 1=英文(默认)    │
  │  0x01-02  │   2   │  目标压力 Pset (×10)           │
  │           │       │  默认 300 = 30.0 kPa           │
  │  0x03     │   1   │  主版本号                      │
  │  0x04     │   1   │  次版本号                      │
  │  0x05     │   1   │  最大推注量 (×10)              │
  │           │       │  默认 70 = 7.0 mL              │
  │  0x06     │   1   │  压迫时间(分钟) 默认 10        │
  │  0x07-08  │   2   │  压力传感器量程 (×10)          │
  │           │       │  默认 500 = 50.0 kPa           │
  │  0x09-0F  │   7   │  保留                          │
  │  0x10-0xFF│  240  │  压力曲线 120 点 (每点2字节)   │
  │           │       │  第0点在 0x10, 每5秒存一点     │
  │  0xF0     │   1   │  最近错误码 (LOG)              │
  └───────────┴───────┴───────────────────────────────┘

  ★ 首次上电时 EEPROM 全为 0xFF，系统自动写入默认值
  ★ SETUP 中每次调整参数自动保存，断电不丢失
  ★ 总容量 256 字节，已用约 251 字节 (含压力曲线)

================================================================================
十、安全机制
================================================================================

  1. 过压保护
     - 压力超过传感器量程的 98% → 立即进入 ERROR
     - 电机紧急停止 (TIM2 关闭, 各相断电)
     - 蜂鸣器 + LED 持续报警
     - 错误码 1 写入 EEPROM

  2. 低电量保护
     - 电量 < 10% (且 PA1 确实接了电池) → ERROR
     - 错误码 2 写入 EEPROM

  3. 手动紧急停止
     - INJECT 阶段按 KEY1 → 立即停电机
     - RETRACT 阶段按 KEY1 → 立即停电机

  4. 零位校准
     - 上电时自动采集 PA0 的 16 次平均值作为零点
     - 后续压力 = (当前ADC - 零点) × 量程 / 4095
     - 排除传感器零漂和噪声干扰


================================================================================
十一、快速调试检查清单
================================================================================

  □ OLED 是否显示 (PB12/PB13 接线正确, SSD1306 正常)
  □ 蜂鸣器是否响  (PB3 接对, 进入 SETUP 按 KEY1 应有提示音)
  □ 按键是否响应  (PB0/PA5/PA6, 按 KEY1 应能从 IDLE → SETUP)
  □ 压力读数      (PA0, IDLE 界面看 BAT 旁边的数字是否合理)
  □ 电机是否转动  (PA10~PA13, 启动后电机应转动)
  □ EEPROM 是否保存 (改 Pset 后复位, 看值是否保持)
  □ 零位校准      (上电时 PA0 不加压, 压力应显示接近 0)
