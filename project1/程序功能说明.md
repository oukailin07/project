# 电机状态监测系统 — 程序功能说明

## 1. 系统概述

基于 STM32F103C8 的电机运行状态实时监测系统，采集振动、温度、三相电流参数，支持 OLED 本地显示、阈值报警、按键参数设置、WiFi 数据上传。

## 2. 引脚分配

| 引脚 | 模式 | 功能 |
|------|------|------|
| PA0 | 模拟输入 | 振动传感器（ADXL1002，单 ADC 模拟三轴） |
| PA1 | 模拟输入 | 温度传感器（MAX31855，模拟） |
| PA2 | 模拟输入 | A 相电流（电流互感器） |
| PA3 | 模拟输入 | B 相电流 |
| PA4 | 模拟输入 | C 相电流 |
| PA5 | 下拉输入 | 按键2 — 数值 + |
| PA6 | 下拉输入 | 按键3 — 数值 - |
| PA15 | 推挽输出 | 按键指示灯（按下任意键高电平） |
| PB0 | 下拉输入 | 按键1 — 确认 / 返回主页 |
| PB1 | 下拉输入 | 按键4 — 切换参数页 / 进入设置 |
| PB3 | 推挽输出 | 蜂鸣器（报警时高电平） |
| PB4 | 推挽输出 | 报警 LED（报警时高电平） |
| PB10 | 复用推挽 | USART3 TX — ESP8266 WiFi |
| PB11 | 浮空输入 | USART3 RX — ESP8266 WiFi |
| PB12 | 推挽输出 | OLED I2C SCL |
| PB13 | 推挽输出 | OLED I2C SDA |

## 3. 按键功能

| 按键 | 主页 | 设置页 |
|------|------|--------|
| 按键1（PB0，确认） | — | 返回主页 |
| 按键2（PA5，+） | — | 当前参数值 +1 步进 |
| 按键3（PA6，-） | — | 当前参数值 -1 步进 |
| 按键4（PB1，切换） | 进入振动阈值设置 | 切换到下一个参数页 |

**设置页循环顺序：** 振动阈值 → 温度阈值 → 电流阈值 → WiFi 间隔 → 回主页

**参数可调范围：**

| 参数 | 步进 | 范围 | 默认值 |
|------|------|------|--------|
| 振动阈值 | 0.5 mm/s | 0.5 ~ 20.0 | 4.5 |
| 温度阈值 | 1 °C | 0 ~ 150 | 85 |
| 电流阈值 | 0.1 A | 0 ~ 10.0 | 10.0 |
| WiFi 上传间隔 | 1 s | 1 ~ 60 | 5 |

## 4. OLED 显示

**主页布局（16px 字体，4 行）：**

```
V: 4.5   T:85.0       ← 振动(mm/s) + 温度(°C)
Ia:3.50  Ib:3.51      ← A相 + B相电流(A)
Ic:3.52  Normal       ← C相电流 + 状态
                      ← 保留行（报警闪烁时清空用）
```

报警时 "Normal" 变为闪烁的 "ALARM!"，闪烁周期 1Hz（500ms 亮 / 500ms 灭）。

页面切换时才清屏，同页面内直接覆盖写入，避免闪烁。

## 5. 传感器数据采集

- **采样方式**：每 100ms 采集一个数据块，每块 100 组（5 通道 × 100 = 500 次 ADC 读数）
- **等效采样率**：每通道 1kHz
- **数据处理**：取 100 次平均值，线性映射到工程单位

**换算公式（0 ~ 3.3V 线性）：**

| 通道 | 公式 | 量程 |
|------|------|------|
| 振动 | `V / 3.3 × 20` | 0 ~ 20.0 mm/s |
| 温度 | `V / 3.3 × 150` | 0 ~ 150.0 °C |
| 电流 | `V / 3.3 × 10` | 0 ~ 10.0 A |

## 6. 报警功能

**触发条件（任一满足即报警）：**
- 振动 > 振动阈值（默认 4.5 mm/s）
- 温度 > 温度阈值（默认 85 °C）
- A/B/C 任意相电流 > 电流阈值（默认 10.0 A）

**报警动作：**
- PB3 蜂鸣器高电平
- PB4 LED 高电平
- OLED 显示闪烁 "ALARM!"

报警响应延迟 < 1 秒（每 100ms 检查一次）。

## 7. WiFi 数据上传

- 接口：USART3（PB10 TX / PB11 RX），波特率 9600
- 间隔：可配置，默认 5 秒
- 格式：JSON 字符串

```json
{"vib":4.5,"tmp":85.0,"Ia":3.50,"Ib":3.51,"Ic":3.52,"alm":0}
```

- `alm`: 0 = 正常，1 = 报警
- Proteus 仿真用 Virtual Terminal 接收

## 8. 系统定时

| 组件 | 频率 | 说明 |
|------|------|------|
| TIM3 中断 | 1 kHz | 系统时间基准 `g_sys_tick_ms` |
| 传感器采样 | 每 100ms 一块 | 100 组/块，等效 1kHz |
| OLED 刷新 | 10 Hz | 每 100ms 更新 |
| 报警检查 | 10 Hz | 每 100ms 检查 |
| WiFi 上传 | 可配 | 默认每 5 秒 |
| 报警闪烁 | 1 Hz | 500ms 交替 |

## 9. 文件结构

```
STM32/
├── main.c                    # 主程序（全部业务逻辑）
├── Src/
│   ├── ADC/adc.c, adc.h      # ADC 驱动（5 通道，PA0~PA4）
│   ├── KEY/key.c, key.h      # 按键驱动（4 键 + PA15 指示灯）
│   ├── LED/led.c, led.h      # 报警驱动（PB3 蜂鸣器 + PB4 LED）
│   ├── OLED/oled.c, oled.h   # OLED I2C 驱动（PB12/PB13）
│   └── USART3/usart3.c, .h   # USART3 驱动（备用，当前未编译）
├── SYSTEM/
│   ├── delay/delay.c, .h     # 延时函数
│   ├── sys/sys.c, sys.h      # 系统宏定义（位带操作）
│   └── usart/usart.c, .h     # USART1/2/3 综合驱动
└── RTE/Device/STM32F103C8/   # 芯片配置、启动文件
```

## 10. 编译与仿真

1. Keil 打开 `Main.uvprojx`
2. 编译生成 `project1.hex`
3. Proteus 中 STM32F103C8 加载 hex 文件
4. 各 ADC 通道接 POT（0~3.3V）模拟传感器输入
5. Virtual Terminal 接 PB10/PB11 查看 WiFi 上传数据
6. 按键一端接 VCC，一端接对应 GPIO（内部下拉，无需外接电阻）
