# Proteus 8 Professional 仿真说明

## 1. 新建工程

1. 打开 Proteus 8 Professional → ISIS Schematic
2. 放置元件（Library 搜索）：

| 标号 | 元件 | Proteus 库名建议 |
|------|------|------------------|
| U1 | STM32F407 | `STM32F407VGT6` |
| U4 | ESP8266 | `COMPIM` 虚拟串口 |
| OLED | 128×64 I2C | `SSD1306` / `OLEDCOLOR12864I2C` |
| 振动 | ADXL1002 模拟 | `POT` → **PA0** |
| 温度 | PT100 仿真 | `POT` → **PC3**（PROTEUS_SIM） |
| 电流×3 | TA18 输出 | `POT`×3 → **PA1 / PA2 / PA3** |
| 蜂鸣器 | FMQ | `SPEAKER` → **PB15** |
| 按键×4 | SW3~6 | `BUTTON` → PA7 / PC4 / PC5 / PB0 |

3. 保存为 `MotorMonitor.pdsprj` / `MotorMonitor.DSN`

## 2. 与原理图一致的引脚连线

| 功能 | STM32 引脚 | 仿真连接 |
|------|-----------|----------|
| 振动 ADC | PA0 | POT 0~3.3V |
| 电流 I1~I3 | PA1 / PA2 / PA3 | POT×3 |
| 温度（仿真） | PC3 | POT 0~3.3V |
| OLED I2C2 | PB10 SCL, PB11 SDA | OLED 模块 |
| ESP8266 USART1 | **PA10 TX**, **PA9 RX** | COMPIM：RX←PA10，TX→PA9，115200 |
| 蜂鸣器 | PB15 | SPEAKER / NPN |
| 报警 LED | PB12 | LED |
| 按键 | PA7 / PC4 / PC5 / PB0 | BUTTON 按下接地 |
| MAX31865 SPI3 | PC10 SCK, PC11 MISO, PC12 MOSI, PA15 CS, PD0 DRDY | 实物模式 |

电源：VDD/VSS、8MHz 晶振（可选）、复位电路。

## 3. 加载固件

1. Keil 编译 `project1.uvprojx`，生成 `project1.hex`
2. 双击 U1 → Program File 选择 `..\project1.hex`
3. Crystal Frequency = **8.0MHz**

## 4. 仿真步骤

1. 点击 **Play** 运行
2. Virtual Terminal 接 COMPIM，查看 JSON 上传
3. 调节 POT：PA0 振动、PC3 温度、PA1~PA3 电流
4. 按键 **PC5（KEY3）**：切换 WiFi 上传间隔

## 5. 常见问题

- **无显示**：OLED 地址 0x3C，检查 PB10/PB11（I2C2）
- **串口无数据**：PA10→COMPIM-RX，PA9←COMPIM-TX，115200
- **按键无反应**：KEY1~4 分别在 PA7、PC4、PC5、PB0
